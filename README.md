# Петелька

Приложение для вязания крючком (PWA, vanilla JS, без сборки).

- **Подошва:** 6 способов (круги, спираль, поворотные ряды, двойная, обвязка стельки, шнур), расчёт по размеру и плотности, пошаговая анимация.
- **Счётчик:** петли и ряды, несколько проектов, цели по кругам из генератора.
- **Плотность:** расчёт по образцу, пересчёт чужой схемы, расход пряжи.
- **Шпаргалка:** обозначения RU / US / UK.

Работает офлайн после первого открытия. Данные хранятся в браузере устройства.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Всё приложение |
| `manifest.webmanifest` | Название, иконки, режим «как приложение» |
| `sw.js` | Офлайн-кэш |
| `icons/` | Иконки |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |

## Обновление

После изменения `index.html` увеличьте `VERSION` в `sw.js` (например, `petelka-v2`), чтобы у установленного приложения обновился кэш.
